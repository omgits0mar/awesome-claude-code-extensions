# Security policy

This repository links to third-party software; it does not distribute or execute those extensions.

## Report a dangerous or compromised entry

If an entry appears malicious, compromised, typo-squatted, credential-stealing, or dangerously misleading:

1. Do not post secrets, working exploits, or victim details in a public issue.
2. Use GitHub’s private vulnerability reporting for this repository when available.
3. If private reporting is unavailable, use the **Request private security contact** issue form with only the project name or catalog URL and no exploit details.

Maintainers may place an entry on security hold or remove it while evidence is reviewed. Removal from this catalog does not remediate the upstream package; report upstream vulnerabilities to the project owner and relevant package registry as appropriate.

## General corrections

Broken links, archived projects, stale descriptions, license changes, and ordinary quality concerns can use the public issue templates.
